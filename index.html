Font sizes and units

  1. The quick brown fox jumped over the lazy dog.
    • Points: pt is an absolute unit, a pt is defined as 1/72 of an inch and is a hold over from the early days of typesetting. The sentence above is styled in 16pt font.
  2. The quick brown fox jumped over the lazy dog.
    • Pixels: px is an absolute unit, it allows full precise control and equal font sizes across devices. The sentence above is styled in 16pt font.
  3. The quick brown fox jumped over the lazy dog.
    • rem: rem is a unit that scales relative to the font size at the root html element. For example, if the root has a defined font size of 16px, and I define a size in the child element of 0.5rem, my font will be 8px.
  4. The quick brown fox jumped over the lazy dog.
    • Absolute units: These are fixed units that are based on the user's default font size.
  5. The quick brown fox jumped over the lazy dog.
    • em: em is a unit that works similarly to rem, however instead of scaling relative to the root element, it scales relative to the parent element.
  6. The quick brown fox jumped over the lazy dog.
    • Percentages: percentages are a relative unit that are functionally the same as em, instead of using a number or decimal to define the relative relationship to the parent element, you use the percentage of the parent's font size. The above sentence is styled in 25% font size.
