SEO - Webcrawlers and Accessibility

  1. Title
    • The title link is what search engines will use for the clickable name of the site in search results. A strong title helps boost rankings and is the first interaction the user will have with the site, making it important to define.
  2. Meta: description
    • The description tag is used by search engines to create the snippet that provides the summary of web content below the page listing in search results. Having a good description and snippet raises your site's search result rating.
  3. Meta: charset="UTF-8"
    • This meta tag ensures webcrawlers correctly interpret the web pages content by using the correct character set.
  4. link: rel="canonical"
    • This relationship type goes in a link tag in the head. It points search engines towards the page it should index, this prevents two pages from the same site from competing with each other.
  5. Headings
    • Structured headings provide a road map for accessibility features and webcrawlers. Good headings give search engines quick hierarchichal access to subtopics, boosting seo performance.
  6. Semantic Tags: header, footer, nav, main, section, etc.
    • Semantic tags not only boost seo performance, but they also improve performance of screenreaders and accessibility in general.
  7. img - alt text
    • Similarly to semantic tags, alt text increases accessibility, improving the experience of the users of those features and boosting SEO performance.

  2. The quick brown fox jumped over the lazy dog.

  3. The quick brown fox jumped over the lazy dog.
    • rem: rem is a unit that scales relative to the font size at the root html element. For example, if the root has a defined font size of 16px, and I define a size in the child element of 0.5rem, my font will be 8px.

  5. The quick brown fox jumped over the lazy dog.

Positioning

  • Static Positioning:
    • Static positioning is the default for all elements; it exists in its "usual" position, without any post placement or relativistic behavior. This is the positioning used for most elements on the page.
  • Fixed Positioning:
    • Fixed positioning takes elements outside of the normal document flow, and moving them into a fixed top layer. This page uses fixed positioning for both the navbar and the footer, allowing the page content to scroll behind them.
  • Relative Positioning:
    • Relative positioning works like static positioning with an extra step. It exists within the normal document flow, but once it's placed, it's shifted. The parent of this list element is relatively positioned from the left of its parent container by 15%.
  • Absolute Positioning:
    • Absolute positioning works similarly to fixed positioning in that elements are moved outside of the document flow into their own layer, they differ in that absolutely positioned elements don't rely on the position of the viewport.
